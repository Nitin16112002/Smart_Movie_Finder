# 🎬 Smart Movie Finder  
Empowering Data-Driven Recommendations 


## 📌 Overview  
The **Smart Movie Finder** is a Python-based recommendation system that suggests movies & anime similar to a user’s favorite movie & anime. It uses **string matching** to find the closest title and **similarity scores** to rank the best recommendations.  

## 🚀 How It Works  
1. The user enters their favorite movie.  
2. The script finds the closest matching movie title from the dataset.  
3. It calculates similarity scores to determine the most relevant movies.  
4. The top 10 recommended movies are displayed.  

## 🛠 Technologies Used  
- **Python** 🐍  
- **pandas** 📊  
- **difflib** 🔍  
- **Similarity Matrix** 📈
